\subsubsection{Nominal Tracking Design}
State-space control methods are used to design controllers that regulate or track a desired reference signal. In this activity, only tracking controllers based on full-state feedback are considered. The controller is designed using the state-space model $(5)$ of the DC servomotor, assuming that all state variables are available for measurement. Both nominal and robust tracking approaches are investigated, with the latter providing improved performance in the presence of model uncertainties and disturbances. The analysis is restricted to a single-input single-output (SISO) system.
